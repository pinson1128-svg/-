# 双语视频预览与文件导出

独立网页，提供泰语/英语视频预览、MP4 下载、SRT 下载、双语 ZIP 打包下载。使用 Python 3 标准库，无需安装依赖。

## 启动

```sh
cd /workspace/-
python3 server.py
```

默认监听本机 8080 端口。在自己的电脑运行后，在浏览器访问该电脑的 8080 端口即可使用。服务器支持视频字节范围请求、拖动播放和 HEAD 请求，下载设置正确的文件类型和附件文件名。

当前云环境设置界面没有提供网页预览或公开网址。启动服务不代表手机或聊天界面能访问它；需要将此项目放到可访问的服务器，或下载到自己的电脑运行。项目实现的是独立应用的文件导出，不会改变聊天平台的附件能力。对外部署时，通过部署平台现有的 HTTPS 和访问控制暴露应用端口。

## 文件

将以下文件放入 `data/`（不纳入 Git）：

| 文件 | 内容 |
| --- | --- |
| `th.mp4` | 泰语版成片 |
| `en.mp4` | 英语版成片 |
| `th.srt` | 泰语字幕 |
| `en.srt` | 英语字幕 |

当前机器已放入用户素材的两版样片。音轨为原创节奏伴奏，尚无人声配音。替换文件即可更新导出，网页刷新后会重新读取可用性；缺文件时禁用相应按钮，打包要求四份文件齐全。可以用 `--data-dir /绝对路径` 指定已有导出目录。

`python3 server.py --host 0.0.0.0 --port 8080` 用于已有网络入口的部署环境。视频通过固定资源 ID 提供，服务不会开放任意目录浏览或任意文件路径下载。

## 验证

```sh
python3 -m unittest discover -s tests -v
```

验证实际 HTTP 下载内容、附件名、视频范围请求、ZIP 文件及缺失文件处理。`/api/assets` 是就绪检查，只有四个资源均 available 才能完整导出双语包。
